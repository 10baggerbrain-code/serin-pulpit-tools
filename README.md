# 세린 설교 도구 (Serin Pulpit Tools)

목회자의 설교 준비를 돕는 AI 프롬프트 템플릿 모음입니다. **무료 공개 · [CC BY 4.0](LICENSE)** — 만든 곳: 세린 유니버스.

AI는 성경 구절, 교리 번호, 실존 인물의 말을 그럴듯하게 지어낼 수 있습니다. 강단에서는 그것이 가장 위험합니다. 그래서 이 템플릿들은 **확실하지 않은 것은 [확인 필요]로 남기고**, 시험 결과와 알려진 한계를 함께 공개합니다.

| 템플릿 | 대상 | 하는 일 |
|---|---|---|
| [THEO-ATLAS](theo-atlas/) | 제칠일안식일예수재림교회(SDA) 목회자 | 설교 초안을 성경 · 기본 교리 28 · 「각 시대의 대쟁투」와 맞춰 보고 보완점 제시 |
| [역사를 사랑하는 목회자용 신학·역사 융합 도구](history-pulpit/) | 역사 설교를 좋아하는 목회자 | 고대 근동사·교회사를 섭리 관점의 연표·사료·적용·설교 도입부·오독 경고로 정리 |

## 시험 결과 요약 (자체 시험, 2026-10-05)
| 템플릿 | 큰 모델 (Claude Opus 5.5) | 작은 로컬 모델 (qwen3:4b) |
|---|---|---|
| THEO-ATLAS | 사람 확인 기준 6개 모두 양호 (자동 채점 5/6, 1개는 채점기 오류) | 인용문 1개를 지어냄 등 문제 남음 |
| 역사 융합 도구 | 6/6, 연도·출처 확인, 유언 인용 지어내기 거절 | 인물 발언·문서·날짜를 지어냄 — 권장하지 않음 |

**큰 모델(Claude, ChatGPT 등)에서 쓰기를 권합니다.** 각 폴더의 README에 문제별 결과와 전체 답변이 있습니다. 문제와 채점 기준은 세린 유니버스가 만들었고, 답변 원문 검토는 AI 도구 Claude로 했습니다.

## 쓰는 법
각 폴더의 `SKILL.md`가 템플릿 본문입니다.
- **Claude Code**: 폴더를 `~/.claude/skills/`에 복사
- **Claude.ai**: 폴더를 압축해 스킬로 올리거나, 프로젝트 지침에 `SKILL.md` 본문 붙여 넣기
- **ChatGPT · Gemini**: `SKILL.md`에서 맨 위 `---` 사이를 뺀 본문을 맞춤 지침에 붙여 넣기

## 공통 안내
- 설교 준비를 돕는 참고 도구입니다. 최종 해석과 선포의 책임은 설교자에게 있습니다.
- 강단에서 쓰기 전에 모든 구절, 연도, 인용문을 원문으로 확인하세요.
- THEO-ATLAS는 교단과 관계없는 개인 제작물이며, 대총회나 어떤 교회 기관도 만들거나 승인하지 않았습니다. "Seventh-day Adventist"는 대총회의 등록 상표입니다.
- 깃허브 액션: 푸시할 때마다 두 템플릿의 형식을 검사합니다. Actions 탭에서 "설교 도구 점검"을 수동 실행하면 시험을 직접 돌릴 수 있습니다(API 키는 저장소 Secrets에 등록).
